# Release history

Every PuzzleBox release, newest first. A release adds its entry here and its player notes at the top of `feature/profile/impl/src/main/assets/whats_new.txt` in the same commit as the version bump. `PROFILE.md` `## Version` holds the current version; a release adds its entry here in the same commit as the version bump.

- **0.42.0**: Community shelves ship (user-approved minor, 2026-11-23, after the owner passed the tablet checks of #2035 and the create FAB #2013): the Community tab is the shelves home (Newest, a spotlight and a shelf per game; Friends and Your puzzles pages; See all with search and filters, #2030, epic community-browse), the old New today / Friends / Yours tabs are gone (#2036), a floating create button opens New puzzle (#2013) and a shared puzzle counts its solves on a player's first entry (#2032; production rules and backfill deployed before the flip, #2035). The Trainer, Insights and StatsFilters flags were removed in #2089 (no visible change).
